# 贡献边界

[中文](contributions.md) | [English](contributions_en.md)

KataCR LiveLoop 是基于 [wty-yy/KataCR](https://github.com/wty-yy/KataCR) 的个人工程适配项目。这里保留上游研究代码和模型能力，同时补充面向 WSL2、NVIDIA GPU、视频评估和 MuMu 模拟器的运行时工程。

## 上游基础

以下内容继承自上游项目，并在本仓库中继续使用：

- KataCR 的研究目标、感知到决策的整体抽象和基础代码结构。
- YOLOv8 目标检测、PaddleOCR、手牌分类及原始视觉特征设计。
- StARformer、DT 等策略模型、训练流程、数据集和模型权重说明。
- 原始数据生成、回放处理、可视化和训练脚本。

## 本适配新增

### 运行时与性能

- 整理 WSL2、Ubuntu 24.04、Python 3.11 和 NVIDIA GPU 的部署路径。
- 打通并验证 JAX、YOLO、Paddle/PaddleOCR 的 GPU 运行路径，同时保留 CPU 回退。
- 增加 CUDA 编译工具、JAX/Orbax checkpoint 恢复和辅助权重问题的诊断。
- 将离线评估的输入、输出、保存、显示、确定性和详细日志选项参数化。

### 感知与可观测性

- 增加 ROI、OCR、卡牌/圣水、状态融合和阶段耗时的诊断入口。
- 增加关键帧抽样、轻量回放、视频评估结果清洗和帧级日志分析。
- 对 `state_update`、`sar_get`、`visual_fusion` 等阶段提供可定位的耗时记录。

### MuMu 实验链路

- 增加 Windows MuMu 与 WSL2 之间的 ADB 探测、截屏和点击适配。
- 增加页面状态识别、训练营流程、坐标比例校准和动作节流。
- 保留从离线视频输入到 MuMu 实时实验的工程化验证脚本。

### 工程入口

- 提供 Windows 启动脚本、WSL 运行脚本和 GPU/ADB 检查脚本。
- 将个人路径、账号信息、视频、模型权重和运行产物移出公开代码。
- 用 README、架构图和运行说明描述从输入到动作执行的完整链路。

## 验证范围

本仓库的“已验证”表示在作者的 WSL2、NVIDIA GPU 和 MuMu 环境中实际运行过，不代表所有设备、驱动和游戏版本都能直接复现。MuMu 自动点击目前属于训练营或低风险实验入口，线上天梯和长期无人值守运行不在当前承诺范围内。

自动下牌表示通过 ADB 执行屏幕点击，不等于重新训练了上游策略模型。模型效果应结合识别准确率、动作有效率、延迟和多局结果评估，不能只由单局胜负判断。
