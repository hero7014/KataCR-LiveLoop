# 公开发布清单

这份清单用于把个人实验工作区整理为可公开的适配仓库或上游 Pull Request。

## 可以公开

- 通用的 WSL2/GPU 设备检查、离线评估参数化和结果记录代码。
- 不包含个人路径的 ROI、OCR、关键帧、回放和性能诊断工具。
- 设备无关的 ADB 输入接口、页面状态识别接口和动作坐标配置方式。
- 贡献边界、运行说明、测试方法和已知限制。

## 需要脱敏或移出

- `C:\Users\...`、`/home/...`、`/mnt/...` 等个人绝对路径。
- 个人视频、截图、模型权重、运行日志、备份清单和 CUDA 安装包。
- MuMu 设备序列号、账号信息、固定端口和只适用于本机的窗口坐标。
- Codex/插件计划、对话交接记录、内部研究笔记和未完成的私人任务清单。

## 上游 Pull Request 原则

上游 PR 只提交可复用、可测试、与具体账号和模拟器无关的改动。建议拆成以下小 PR：

1. 离线评估器参数化与输出路径兼容。
2. PaddleOCR GPU/CPU 回退和设备检查。
3. Orbax/JAX checkpoint 跨设备恢复。
4. 缺少辅助权重时的明确降级模式。
5. 与具体模拟器无关的 ADB 输入后端抽象。

MuMu 专用启动脚本、个人路径和实验日志留在个人适配仓库，不混入上游 PR。
